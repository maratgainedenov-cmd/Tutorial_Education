## Launch Day (Day 0)

### Morning (6-12 hours before launch)

- [ ] Producer gives final approval (game build + messaging)
- [ ] All scheduling tools prepped (TikTok scheduling app loaded with posts)
- [ ] Discord moderators online and briefed
- [ ] Community manager ready for 24-hour monitoring
- [ ] QA team on standby (monitor for launch crashes/bugs)

### Launch Hour (Exactly at launch)

**Simultaneous across all channels:**

1. **itch.io**:
   - [ ] Game goes live on itch.io
   - [ ] Launch post pinned in comments
   - [ ] Game page refreshed and visible to public

2. **Discord**:
   - [ ] Launch announcement posted to #announcements
   - [ ] Pinned for 24 hours
   - [ ] Moderators monitoring

3. **TikTok**:
   - [ ] 2-3 posts published immediately (teaser + download link)
   - [ ] Videos uploaded and pinned to profile

4. **Email**:
   - [ ] Launch email sent to subscriber list
   - [ ] Subject line: compelling but not clickbait

5. **In-Game** (if applicable):
   - [ ] Launch notification posted (if in-game messaging system exists)

**DO NOT** stagger posts. Everything goes live within 5 minutes for maximum impact.

### First 24 Hours

**Every Hour (6 AM - 6 PM)**:
- [ ] Monitor itch.io comments (respond to every comment)
- [ ] Monitor TikTok comments (engage with viewers)
- [ ] Monitor Discord #general and #feedback (respond to questions)
- [ ] Check for crash reports / game-breaking bugs (QA priority)
- [ ] Track player count / session stats

**Key Responses**:
- "How do I download?" → Direct link + instructions
- "How do I play?" → Link to tutorial (in-game or YouTube)
- "Is this on mobile?" → "Not yet, PC only. Mobile coming 2026"
- "Can I play with friends?" → "Yes! Online and local co-op"
- "[Bug report]" → "Thanks for reporting! We're on it" (escalate to QA)

**Do NOT**:
- Go to bed (serious bugs can happen)
- Ignore negative comments (they set tone for community)
- Make promises about patches
- Argue about balance (save for dev blog explanation)

### Hours 24-48

- [ ] First day stats collected (downloads, peak concurrent, retention)
- [ ] Thank you post on all channels (celebrating launch)
- [ ] Address any hot topics from comments (1-2 feedback themes)
- [ ] Post 2-3 more TikTok clips (keep momentum)
- [ ] Developer Q&A thread opened (answer top player questions)

## Launch Month (Days 8-30)

### Weekly Cadence (Mondays or Thursdays)

- [ ] TikTok: 3-4 posts (60% highlights, 20% vlogs, 15% memes, 5% education)
- [ ] Dev blog: 1 post (balance explanation, feature deep-dive, or behind-the-scenes)
- [ ] Feedback summary: Email to team with trends
- [ ] Patch notes: If build released, published same day
- [ ] Community spotlight: 1 player/moment featured on all channels

### Monitor & Adjust (Weekly)

- [ ] **Retention**: Is D7 retention staying above 30%? If dropping, investigate why
- [ ] **Balance**: Are win rates stable (50/50)? If Blocker >55% or <45%, consider hotfix
- [ ] **Engagement**: Are TikTok videos getting 10K+ views? If not, adjust content type
- [ ] **Sentiment**: Are players happy? Count positive vs. negative comments (target 75%+ positive)
- [ ] **Bugs**: Critical bugs patched within 48 hours?

### Scaling Content

- [ ] Week 2: Recruit 1-2 community moderators (Discord, itch.io)
- [ ] Week 3: Reach out to 3-5 micro-influencers (10K-100K followers) for playthrough
- [ ] Week 4: Post first YouTube video (5-10 min tutorial or highlight reel)

## Go / No-Go Checklist (24 Hours Before Launch)

**Producer asks: "Are we ready?"**

Answer YES only if all of these are TRUE:

- [ ] Game is stable (< 2 crashes per 10 playthroughs)
- [ ] All major features work (multiplayer, abilities, UI readable)
- [ ] itch.io page is live and tested
- [ ] TikTok account is set up with 3-5 posts scheduled
- [ ] Community guidelines are published
- [ ] Crisis communication plan is reviewed + agreed
- [ ] Moderators are trained and online
- [ ] All team members know their roles + have contact numbers
- [ ] Marketing docs are finalized and shared with team
- [ ] Community manager has 24-hour availability (sleep rotation if multi-timezone)

If any answer is NO, push launch by 3-7 days. A delayed launch is better than a chaotic one.

- [x] 500+ downloads
- [x] 50+ peak concurrent players
- [x] 60%+ Day 1 retention
- [x] 75%+ positive community sentiment
- [x] 0 community crisis incidents (good moderation)

- [x] 1000+ TikTok followers

## Failure Looks Like (Month 1)

- [ ] < 100 downloads (marketing not reaching audience)
- [ ] < 10 peak concurrent (no multiplayer health)
- [ ] < 30% Day 1 retention (game doesn't hook players)
- [ ] < 50% positive sentiment (major gameplay/balance issues)
- [ ] Multiple community incidents (moderation not effective)
- [ ] No hotfixes despite bug reports (team not responding to feedback)
- [ ] < 100 TikTok followers (content not resonating)
- [ ] 0 dev blogs (communication broke down)

**If this is you**: Emergency team meeting. Decide: pivot content strategy? Add features? Fix bugs? Extend closed beta? Don't push forward without identifying root cause.

## Contingency Plans

### If Launch Crashes 100% of Players
1. Pull game from itch.io immediately
2. Post: "We're pulling the game to fix a critical issue. We'll relaunch in [48 hours]"
3. All-hands on deck: debug, test, relaunch
4. Apologize + offer compensation (cosmetic or currency)

### If Balance is Wildly Wrong (One Role 70%+ Win Rate)
1. Hotfix within 48 hours
2. Dev blog explaining what went wrong + why
3. Rebalance within 1 week

### If Community Turns Toxic
1. Enforce community guidelines strictly (no tolerance for first offense)
2. Hire additional moderator
3. Post community health update (what we're doing)

### If Sales Are Abysmal (< 50 downloads/week by week 3)
1. Emergency marketing review (is content reaching right audience?)
2. Pivot TikTok strategy (try different content mix)
3. Reach out to gaming press/reviewers for coverage
4. Consider pricing change (free → paid, or vice versa)
