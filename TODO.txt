========================================
  ЧТО ОСТАЛОСЬ СДЕЛАТЬ В UNITY EDITOR
========================================

Код уже написан. Нужно только настроить в редакторе.

----------------------------------------
1. СОЗДАТЬ EXIT ОБЪЕКТ В СЦЕНЕ
----------------------------------------
- Hierarchy → Create Empty → назвать "Exit"
- Add Component → Exit
- Add Component → Box Collider 2D
    → Size: (1, 1)
    → Is Trigger: галку поставить

----------------------------------------
2. ДОЧЕРНИЕ ВИЗУАЛЫ ВНУТРИ EXIT
----------------------------------------
Внутри "Exit" создай два дочерних объекта:

  "Open" (когда выход свободен):
  - Create Empty → назвать "Open"
  - Add Component → Sprite Renderer
  - Цвет: зелёный
  - Перетащить в поле "Open Visual" на Exit

  "Blocked" (когда тетрис закрыл выход):
  - Create Empty → назвать "Blocked"
  - Add Component → Sprite Renderer
  - Цвет: красный
  - Перетащить в поле "Blocked Visual" на Exit

----------------------------------------
3. НАСТРОИТЬ ПОЗИЦИЮ ВЫХОДА
----------------------------------------
- На компоненте Exit → поле "Grid Pos"
    → X = 0, Y = 2  (левый край сетки)
- Поле "Board" → перетащить Board из сцены
- В Scene View увидишь зелёный куб = клетка выхода

----------------------------------------
4. WIN PANEL (экран победы)
----------------------------------------
- Найти Canvas в Hierarchy (или Create → UI → Canvas)
- Внутри Canvas: UI → Panel → назвать "WinPanel"
- Внутри WinPanel:
    → UI → Text → написать "Персонаж победил!"
    → UI → Button → написать "Рестарт"
       → OnClick: перетащить GameManager → выбрать Restart()
- WinPanel → в Inspector убрать галку (SetActive = false)
- Выделить GameManager → поле "Win Panel" → перетащить WinPanel

----------------------------------------
5. ВКЛЮЧИТЬ ЛОКАЛЬНЫЙ РЕЖИМ (БЕЗ PHOTON)
----------------------------------------
- Выделить GameManager в Hierarchy
- Поставить галку "Local Debug Mode" = true

========================================
  ПОРЯДОК ТЕСТА
========================================
1. Запустить игру
2. Exit клетка должна светиться зелёным
3. Довести персонажа до зелёной клетки → появится WinPanel
4. Положить тетромино на клетку Exit → станет красной → персонаж не пройдёт
